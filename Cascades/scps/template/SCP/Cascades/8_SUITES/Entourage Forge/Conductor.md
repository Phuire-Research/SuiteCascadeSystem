## Band 3.5 — the Page Duplication (the compiled registration)

The minted Suite 8 becomes a REAL page through the PROVEN pipeline — the same one the
installation agent runs (the S9-DomainPageCreate shape, `Cascades/8_SUITES/SCS Bridge/
Strategy/S9-DomainPageCreate.md` at the bridge root):

```
cd {workspace root} && scs suite8:page {NamePascal} --display-name "{minted name}" --designation {thisScp}
```

— which copies the page concept, renames its 24 files, replaces the four token pairs,
lands the three anchored registration inserts (the island import · the concept
composition · the REGISTERED_MUXONOMICS entry — the ONE flat registry every nav/route/
island consumer reads), then gates on tsc + build:client. NO `--home` — the home route
belongs to the install's primary domain alone.
**The Concluders**: the command's `✓ Suite 8 page created` signal · tsc 0 · the build
green · the sidebar lists the Suite on the next load. **The branch law**: Band 3.5
edits `src/concepts` and rebuilds — it runs ONLY on a working (`b/`) branch; the door's
Turn Over Request is the gate that puts the conduction there.

## The Conference Rows

**The Conference surface**: the Forge's terminal — every Conference row renders as an
in-context Shatterite Menu via `AskUserQuestion` (one decision per stage; the user's
free text via Other is first-class). No `Cascades/Extended/` menu files ride this
conduction.

- Band 1 closes on the user's domain — no research fires without it.
- Every Band boundary fires the per-Band Conference (Proceed · Adjust · Re-enter).
- Band 6 closes on the user's sight of the final hand-off menu — the hand-off is theirs.
- Any Band may be re-entered by the user's word; the Forge re-conducts from there.

## The Dispatch Grammar (the Teal Claude inheritance)

Dispatched Bands carry: the absolute repo root · the minted Suite 8's dir · the Band's
single deliverable · the Muxistration demanded (the artifact + its Concluder). A Band
that returns narrative without artifact is re-dispatched, never accepted.

## The Close Contract

At Band 6 the Forge: (1) rewrites the minted Onboard.md (the creation body OUT, the
domain body + Starting Menu IN); (2) proves the placeholder absent (grep); (3) reports
the hand-off — the Suite 8's own Shatterite Menu is now its user's door. The Forge's
aspect ENDS at creation: stewardship belongs to the Suite 8's own Maintainer.
