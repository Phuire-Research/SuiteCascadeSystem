## Conductor Hand-off Pattern

Whichever Foundation Shape + Closure Pattern the user selects, the Conductor (teal-claude) takes the resulting Banded Vermillion Plan and:

1. **Tier Fork Check**: Reads `ONYX-TIER-N.md` line count. If >400 → fork Tier-(N+1) FIRST per `MACRO-DIAMOND-GUIDE.md` §3 fork-FIRST discipline.
2. **Foundation Magic Shotgun Dispatch**: Single message · N parallel Tier-1 Agent calls per selected Foundation Shape. Each Foundation Suite writes `SUITE-{N}-{COLOR}-{MACRO-NAME}-{ASPECT}.md` in `Cascades/Working/` with disjoint scope.
3. **Synthesis**: Conductor reads all N returns · documents R3 vs R6 Reconciliation (per `FOUNDATION-SUITES-GUIDE.md` §4) · writes Macro WGB at `Cascades/Working/DIAMOND-TIER-{MACRO-NAME}.md`.
4. **Cerulean Task Chain**: Macro WGB sub-Diamond list becomes Cerulean tasks. Each task is a separate cycle engagement.
5. **Sub-Diamond Cycles**: For each sub-Diamond, dispatch Foundation Magic Shotgun (Triplet/Quartet per WGB config) → R5 Cobalt actualization → Concluder Gate.
6. **Macro Close**: Per Closure Pattern selected. HALT-GATE smoke. Version bump. IMDT-out contract.

## Conductor Self-Check (Pre-Render)

Before rendering this menu, the Conductor verifies:

1. `Cascades/Cascade.json` exists and is readable
2. `Cascades/Documentation/Cascades/MACRO-DIAMOND-GUIDE.md` exists
3. `Cascades/Documentation/Cascades/MAGIC-SHOTGUN-PATTERN.md` exists (Macro relies on Foundation Magic Shotgun)
4. `Cascades/Documentation/Cascades/FOUNDATION-SUITES-GUIDE.md` exists (3-agent discipline)
5. Active Diamond present (Cascade.json → activeDiamond) — if user is mid-Diamond, confirm Macro is the right scope shift
6. `Cascades/8_SUITES/Teal Claude/Conductor.md` includes Macro Diamond routing protocol (per Conductor v1.11+)

If any check fails → render error pane with corrective instruction instead of the menu.

## Macro Diamond Contract (Self-Check Before Dispatch)

Before issuing the Macro Open Banded Plan, the Conductor verifies:

1. **Macro-class scope confirmed** with user (per `MACRO-DIAMOND-GUIDE.md` §7)
2. **Onyx tier line count** assessed · fork-FIRST decision made
3. **Macro Name** confirmed (becomes WGB filename suffix `DIAMOND-TIER-{MACRO-NAME}.md`)
4. **Foundation Shape** matches manifold complexity per `MAGIC-SHOTGUN-PATTERN.md` §5
5. **R7 at Foundation level** included for Macro opens (per `SG-Macro-Open.md` §Why R7)
6. **HALT-GATE script** drafted (refined post-Foundation return)
7. **IMDT-out contract** anticipated (what bindings will future Macros consume)
8. **Closure Pattern** selected (A embedded · B retrospective)

If any check fails → re-plan. This is the **Macro Diamond Contract**.
