## Diameter to Magic Shotgun

Macro Diamond and Magic Shotgun are **bidirectional companions**:

- **Macro Diamond** = trajectory-scale composition (multi-cycle arc with sub-Diamond chain)
- **Magic Shotgun** = dispatch-scale composition (Foundation Suites parallel at-once)

Every Macro Diamond's **Foundation Grounding Cycle** uses a Magic Shotgun shape (4-Suite / 5-Suite / 3-Stage). Every Magic Shotgun beyond standard sub-Diamond scope tends to nest inside a Macro Diamond (Refinement Macros · Macro opens · cross-Macro seam closure).

The **4-Tier Magic Shotgun** (per `MAGIC-SHOTGUN-PATTERN.md` §2.5):

- **Tier-0** (Foundation-Only → Diamond) — Foundation Suites parallel → Diamond planning surface · user reviews · then engages Tier-1 or Tier-2
- **Tier-1** (Traditional 2-Stage) — Foundation Suites → Cobalt
- **Tier-2** (3-Stage Per-Isolation) — Foundation → R3 Per-Isolation → R5 Per-Isolation
- **Tier-3** (Full Chain · potential future) — Foundation → Diamond → R3 Per-Isolation → R5 Per-Isolation

Macro Diamonds typically use **Tier-1 or Tier-2** at Foundation Grounding · Refinement Macros use **Tier-2** (3-Stage) for Diamond-of-Isolations.
