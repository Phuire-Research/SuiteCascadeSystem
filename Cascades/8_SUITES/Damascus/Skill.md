# Damascus — Skill

## S1 · Induct-and-Revise

1. READ the inducted source verbatim from the named Working board (never a paraphrase).
2. DRAFT the revision: fix spelling/typos · smooth grammar and flow · preserve voice,
   framing, and every substantive claim · soften capitalization only where public reading
   demands · hold the Charter Laws (Instance.md).
3. COMPOSE into the target surface's existing HiFi frame (reuse the surface's section
   idioms; retire replaced markup AND its now-dead styles — no dead code).
4. VERIFY: every sentence traces to the source · the firewall grep is clean ("Consumers" ·
   scare-quotes · taxonomy · Muxonomy · Vermillion = zero hits in the public output) ·
   the surface's build gates pass.

## S2 · The Pin Ripple

When a doctrine pin rides the induction (e.g. the AppKiller pin: the SCP is the UI
representation of the StratiDECK system — Stratimux Concept Program), land it at every
surface that speaks the subject's nature, elevated within the source's own framing.
